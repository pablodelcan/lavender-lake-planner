# Lavender Lake Floor Planner

A 3D floor planner for the bookstore pop-up at Lavender Lake. It is a single static page: open `index.html`, or deploy the folder as-is (no build step).

- `index.html` — the planner
- `assets/models.json` — 3D models, book and zine covers, posters and textures
- `renders/` — exported plans, stills and walkthrough videos

Room dimensions and furniture positions are estimated from photographs, not measured.
